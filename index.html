Questions

Before you ask.

Do you work fixed-price or hourly?

Both. Most projects are a fixed price split into milestones, so you know the total up front and only release payment as each part is delivered. Open-ended or ongoing work can be hourly.

Can you work with my existing code or stack?

Yes. A lot of my work is extending, refactoring and stabilising existing systems, from web apps to C#/.NET desktop software. I read the code first and suggest the smallest safe change.

Do I own the code?

Yes. You receive the full source code, any 3D or design source files, and the documentation needed to run and deploy it.

What happens after launch?

Every project can include a support period after launch for fixes and small changes, agreed in the quote. Longer-term maintenance can continue hourly or on a retainer.

How do we start?

Send a message on Upwork or by email with what you want to build. I reply with questions, a plan and a quote. Hiring through Upwork keeps payments protected for both of us.
